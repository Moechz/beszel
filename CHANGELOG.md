# Changelog

All notable user-visible changes to the Beszel TOS application package.

## 0.21.2-1 — 2026-11-15

### Added
- First release. Beszel (`henrygd/beszel:0.21.2`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8145 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/beszeldocker/`.
