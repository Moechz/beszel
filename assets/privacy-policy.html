Beszel Monitor — Privacy Policy

本文档为双语隐私政策。英文版在前，中文版在后。（This document is bilingual: English first, Chinese below.）

1. Overview

Beszel Monitor is a server-monitoring application that runs entirely on your own NAS device (TerraMaster TOS 7). The application itself does not collect, transmit, or share any personal data with the packager (Moechz) or any third party. There are no analytics, no telemetry, no tracking, and no advertising SDKs. Metrics are collected from your own machines and stored only on your NAS.

2. Data stored on your device

DataLocationPurpose
Admin account (username + password hash), app settings, monitored-host list/var/lib/beszelmonitor/data.db (SQLite)Dashboard login and configuration persistence
Historical metrics (CPU, memory, disk, network, temperatures, Docker stats)/var/lib/beszelmonitor/The charts and alerts you asked the app to keep
Agent key fingerprint cache/var/lib/beszelmonitor/agent/Host-key verification when pairing agents
App configuration/usr/local/beszelmonitor/beszelmonitor.env, beszelmonitor-agent.envServer settings; agent pairing token
Service logssystemd journalOperational diagnostics

All of this data stays on your device. It is never uploaded by the application to the packager or anyone else.

3. Your rights: access, correction, deletion

  • Access: open the web UI, or read the files listed above (e.g. sqlite3 /var/lib/beszelmonitor/data.db).
  • Correction: edit settings in the web UI or edit the .env files at any time.
  • Deletion: remove hosts or data in the web UI; apt remove --purge beszelmonitor (or TOS App Center uninstall) removes configuration and all monitoring data. No remote copy exists anywhere because nothing was ever uploaded.

4. Third-party network access (user-initiated only)

The application contacts external services only through features you explicitly configure:

  • Agents you add: the hub on your NAS connects over your network to the agent machines you register. Metrics traffic stays between your machines.
  • Optional integrations you configure (e.g. email/SMTP notifications, webhooks): data goes directly from your NAS to the service you entered. No intermediary sees it.
  • Update check: the dashboard's built-in update check (only when an admin opens it) queries the upstream project's releases on github.com.
  • Nothing else: no data is sent to Moechz, to any Moechz-operated server, or to any other intermediary.

5. Accounts and children

The dashboard has a single local admin account created by its first user. There is no cloud account, no sign-up, and no processing of children's data. The web UI is a local service on your LAN, reachable through the TOS web route.

6. Changes and contact

This policy ships inside the application package and is served at /beszelmonitor/privacy-policy.html on your device. For questions or reports: https://github.com/Moechz/beszel (Issues).

Beszel Monitor — 隐私政策（中文）

1. 概述

Beszel Monitor 是完全运行在您自己的 NAS 设备（TerraMaster TOS 7）上的服务器监控应用。应用本身不向打包者（Moechz）或任何第三方收集、传输、共享任何个人数据：无统计、无遥测、无跟踪、无广告 SDK。指标数据从您自己的机器采集，且只存储在您的 NAS 上。

2. 存储在您设备上的数据

数据位置用途
管理员账号（用户名 + 密码哈希）、应用设置、被监控主机列表/var/lib/beszelmonitor/data.db（SQLite）仪表盘登录与配置持久化
历史指标（CPU、内存、磁盘、网络、温度、Docker 容器统计）/var/lib/beszelmonitor/您要求应用保留的图表与告警数据
agent 密钥指纹缓存/var/lib/beszelmonitor/agent/接入 agent 时的主机密钥校验
应用配置/usr/local/beszelmonitor/beszelmonitor.env、beszelmonitor-agent.env服务设置；agent 接入令牌
服务日志systemd journal运行诊断

以上数据全部保存在您的设备上，应用不会将其上传给打包者或任何其他方。

3. 您的权利：访问、更正、删除

  • 访问：打开网页界面，或直接读取上述文件（如 sqlite3 /var/lib/beszelmonitor/data.db）。
  • 更正：在网页界面修改设置，或随时编辑 .env 配置文件。
  • 删除：在网页界面删除主机或数据；apt remove --purge beszelmonitor（或 TOS 应用中心卸载）会删除配置与全部监控数据。因从未上传，任何地方都不存在远程副本。

4. 第三方网络访问（仅用户主动触发）

应用仅在您显式配置的功能中访问外部服务：

  • 您添加的 agent：NAS 上的 hub 通过您的网络连接您注册的 agent 机器，指标流量只在您的机器之间流转。
  • 您配置的可选集成（如邮件/SMTP 通知、webhook）：数据由您的 NAS 直发您填写的服务，无任何中间方。
  • 更新检查：仪表盘内置的更新检查（仅管理员打开时）会查询上游项目在 github.com 的发布信息。
  • 其他：不向 Moechz、Moechz 运营的任何服务器或任何中间方发送数据。

5. 账号与儿童

仪表盘仅有一个由首个使用者创建的本地管理员账号。没有云账号、没有注册流程、不处理儿童数据。网页界面是局域网本地服务，经 TOS web 路由访问。

6. 变更与联系

本政策随应用包分发，并在您的设备上经 /beszelmonitor/privacy-policy.html 提供。疑问或报告：https://github.com/Moechz/beszel（Issues）。
